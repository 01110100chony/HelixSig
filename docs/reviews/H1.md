# H1 Review

## Scope and frozen contracts
H0 technical approval is prerequisite. Implement a single-crate Cargo build and
synchronous borrowed CXX bridge to the independent native kernel.

Allowed: Cargo.toml/lock, build.rs, src/lib.rs, src/bridge.rs, cpp/ffi/adapter.*,
tests/numerical.rs, H1 additions to verify.sh/CI and relevant documentation.
Exclude ingestion, CLI, workers, channels, metrics and Parquet. Do not modify
native mathematical semantics or compile the kernel twice into one executable.

Leader-owned interface decisions:
- Shared NativeResult: status:u32, baseline:f64, peak_amplitude:f64,
  peak_index:u32, integral:f64. Explicit field mapping, no layout reinterpretation.
- process_event(samples:&[f64], baseline_samples:u32)->Result<NativeResult>.
- process_batch(samples:&[f64], width:usize, baseline_samples:u32,
  output:&mut[NativeResult])->Result<()>.
- Event errors preserve native statuses; batch structural/config errors use Err
  without modifying output. Numerical errors remain per-event statuses.
- Adapter may use a fixed stack array of 64 native results before copying small
  result structs. No sample copying in C++, no retained references or callbacks.
- build.rs invokes CMake with BUILD_TESTING=OFF, then cxx-build compiles only
  generated bridge/adapter using the same compiler and C++20.
- Observed G0 versions: Rust 1.98.1, cxx/cxx-build 1.0.200, cmake 0.1.58.

Required acceptance: compare fixtures with independent reference.json; event/batch
parity; B=1/64, partial and empty batches; NaN/Inf and bad shapes/config; unchanged
output on structural errors; input immutability; concurrent calls on disjoint
buffers; fmt/clippy/tests; H0 regression; independent FFI/build review.
