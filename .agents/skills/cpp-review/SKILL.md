# C++ Review
Focus on ownership/lifetime, RAII, UB, `std::span`/view lifetimes, dangling references,
iterator invalidation, conversions, exception/error boundaries, thread safety/reentrancy,
shared mutable state, hot-path copies and correctness-relevant CMake/compiler/sanitizer issues.
Avoid style bikeshedding and speculative optimization.
Return severity, file:line, evidence, impact and minimal remediation.
