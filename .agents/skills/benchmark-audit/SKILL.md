# Benchmark Audit
Check timing boundaries, setup/I/O contamination, synchronization/drain, warmups, repetitions,
release builds, deterministic workload, compiler/hardware/OS capture, percentiles, units,
per-event/per-batch denominators, FFI batching contamination, memory semantics, hidden drops and comparison fairness.
Return invalid claims, blockers, missing metadata and the smallest experiment required.
