# Build Debug
Inspect diagnostics, generated bridge code, Cargo build scripts, CMake targets, include paths,
link order, ABI/config mismatch, Debug/Release mismatch, sanitizer flags/runtimes, stale caches and CI differences.
Return observed failure, likely root cause, evidence, minimal repair and verification command.
